# MeWe Soshi-Free Userstyle

_A Userstyle for MeWe.com to remove Soshi-related elements. This includes the Wallet menu nav button, the promoted posts (ads), locked posts, and the Tipping button on posts and profiles._

## Installation

## [📦 UserCSS file ![Install directly with Stylus](https://img.shields.io/badge/Install%20directly%20with-Stylus-00adad.svg)](https://raw.githubusercontent.com/kevin-guertin/mewe-soshi-free/master/mewe-soshi-free.user.css)

A Userstyle extension is required. I highly recommend using **_Stylus for [Chrome](https://chrome.google.com/webstore/detail/stylus/clngdbkpkpeebahjckkjfobafhncgmne) or [Firefox](https://addons.mozilla.org/en-US/firefox/addon/styl-us/)_**.

Then, after installing Stylus, click on the "📦 UserCSS file" link above, and when a new window appears, click "Install style" on the left. I highly recommend enabling checking for updates.

Refresh any MeWe tabs if the style isn't showing immediately.

### Install This Theme UserStyles.world

This Userstyle is available on **UserStyles.world** [here](https://userstyles.world/style/27034), but I highly recommend you use the UserCSS version here instead.
